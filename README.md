# One Word, First Thought

This entry writes exactly one word to `entry.txt` and nothing else — no extra files, no trailing newline, no explanation. One word, first thought, exactly as the bounty asks.

```
firefly
```

## How it works

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This creates the output directory if needed and writes the word `firefly` to `entry.txt` inside it.
